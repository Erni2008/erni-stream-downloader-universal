ERNI Stream Downloader для macOS

В этой папке лежит готовое приложение:

ERNI Stream Downloader.app

Как запускать:

1. Перетащите ERNI Stream Downloader.app на рабочий стол или в Applications.
2. Откройте двойным кликом.
3. Если macOS покажет предупреждение безопасности:
   - нажмите правой кнопкой по приложению;
   - выберите Open / Открыть;
   - подтвердите запуск.

Важно:

На Mac должны быть установлены yt-dlp и ffmpeg.

Команда установки:

brew install yt-dlp ffmpeg

Если Homebrew не установлен, сначала установите Homebrew:

https://brew.sh

Папка с исходным кодом для Mac не нужна обычному пользователю.
Обычному пользователю достаточно файла ERNI Stream Downloader.app.
